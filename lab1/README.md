# Laboratorul 1

La exercițiul 3, obținem intervalul de timp de 1/2000 s, adică 0.5 milisecunde (ms). Pentru cerința de la punctul (b), știind că un eșantion ocupă 4 biți, vom obține într-o secundă 4 biți * 2000 1/s = 8000 biți/s, sau 1000 B/s. Deci, într-o oră vom folosi 3600 s * 1000 B/s = 3.600.000 de B.
